# ResearchBench v1.1.0 Audit

## 1. Fabricated Artifact Auditing
* **Affected Module:** esearchbench/audit/artifacts.py
* **Issue:** Claimed semantic validation of methodology but merely checked for the presence of string literals (e.g., "{folds}-fold" or "x") using OCR and PyMuPDF. Completely invalid as semantic verification.
* **Replacement:** Replaced with a structured claim extraction architecture. Uses an optional local LLM backend (Ollama) to extract JSON schemas (e.g., {"claim_type": "cross_validation", "folds": 5}) and falls back to an honest deterministic reporting of textual evidence without claiming semantic verification.

## 2. Invalid Conformal Prediction
* **Affected Module:** esearchbench/evaluation/conformal.py, esearchbench/cli.py
* **Issue:** Calculated naive empirical quantiles directly on OOF residuals. This violates exchangeability since OOF predictions are pooled across overlapping training sets, providing invalid confidence bounds.
* **Replacement:** Implemented rigorous Split-Conformal Prediction. Models are trained on a proper subset, calibrated on an isolated calibration holdout to calculate valid nonconformity scores, and evaluated appropriately.

## 3. Probability Calibration Leakage
* **Affected Module:** esearchbench/cli.py
* **Issue:** Previously absent or naive.
* **Replacement:** Implemented rigorous probability calibration (Platt Scaling and Isotonic Regression) using strict calibration holdout sets to prevent leakage, outputting Brier Score and Expected Calibration Error (ECE).

## 4. Sparse Matrix RAM Bomb
* **Affected Module:** esearchbench/evaluation/preprocessing.py
* **Issue:** OneHotEncoder and TfidfVectorizer were hardcoded to sparse_output=False. High-cardinality or NLP datasets would silently flatten sparse matrices, causing instant Out-of-Memory (OOM) crashes.
* **Replacement:** Preserved sparse arrays throughout the pipeline. Added a memory safety guard that computes ows * cols * bytes prior to any necessary densification, aborting if it exceeds configurable thresholds.

## 5. Broken Auto-Balancing
* **Affected Module:** esearchbench/evaluation/comparison.py
* **Issue:** Used a blind setattr(model, "class_weight", "balanced"). This silently failed for VotingClassifier and nested pipelines, resulting in unbalanced training while reporting that balancing was applied.
* **Replacement:** Implemented estimator-aware parameter injection. Recursively inspects pipelines/ensembles to safely inject class_weight where supported, and honestly reports the applied configuration.

## 6. Static Visualizations
* **Affected Module:** esearchbench/evaluation/performance_plots.py, eport.html
* **Issue:** Hardcoded base64 PNGs. Not interactive.
* **Replacement:** Replaced with Plotly JSON generation, rendering interactive offline-capable charts.
