# ResearchBench v1.0.1 Roadmap

With the architecture stabilized in 1.0.0, the 1.0.1 update introduces two powerful automated heuristics to handle real-world dataset flaws without requiring manual researcher intervention.

## 1. Auto-Balancing (Smart Baselines)
- **Problem**: Highly imbalanced datasets (e.g., 95% negative, 5% positive) cause standard models to trivially predict the majority class. While v0.9 audited this, it didn't fix it.
- **Solution**: If the dataset exhibits severe imbalance (minority class < 15%), ResearchBench will dynamically inject class_weight='balanced' into supported scikit-learn models (LogisticRegression, RandomForest, DecisionTree) before evaluation.

## 2. Learning Curve Diagnostics
- **Problem**: Researchers often don't know if their model is suffering from High Bias (underfitting) or High Variance (overfitting/needs more data).
- **Solution**: Compute an automated Learning Curve (sklearn.model_selection.learning_curve) for the best-performing baseline.
- **Output**: A base64-encoded line plot in the HTML report showing Training Score vs Cross-Validation Score as the dataset size increases, instantly diagnosing data scarcity vs. model ceiling.
