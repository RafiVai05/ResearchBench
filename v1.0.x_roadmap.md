# ResearchBench v1.0.2 - v1.0.5 Patch Roadmap

This roadmap covers the continuous integration of four sequential patches to harden the analytics and diagnostics of the framework.

## v1.0.2: The "Outlier & Anomaly" Update
- **Feature**: Automated Outlier Detection.
- **Implementation**: Inject an IsolationForest into the dataset profiling phase (udit.py) to detect and report the percentage of highly anomalous records.

## v1.0.3: The "Dimensionality" Update
- **Feature**: PCA Variance Assessment.
- **Implementation**: Compute Principal Component Analysis (PCA) on numeric features to determine how many components explain 95% of the variance. Warns researchers if the dataset is mostly redundant dimensions.

## v1.0.4: The "Feature Importance" Update
- **Feature**: Global Feature Importance Visualizations.
- **Implementation**: Extract eature_importances_ or coef_ from the best evaluated pipeline and generate a Top-10 Feature Importance bar chart (embedded as a base64 PNG in the HTML report).

## v1.0.5: The "Markdown Export" Update
- **Feature**: Automated Markdown Reporting.
- **Implementation**: Automatically generate a <dataset>_best_model_report.md alongside the HTML and Joblib artifacts, perfectly formatted for GitHub repositories and CI/CD logs.
